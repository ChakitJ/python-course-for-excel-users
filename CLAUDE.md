# Project Context

## About
Data analysis & automation work — hospital interpreter rosters, Excel reports,
dashboards, and Python-assisted data operations. Also a Python course for Excel
users (pandas, pivot tables, data visualization, web scraping).

## Tech Stack
- Python 3 (pandas, numpy, openpyxl, matplotlib, seaborn) — virtualenv at `~/venv`
- Excel / Power Query (M) / Power Automate / Office Script
- Jupyter notebooks for analysis and teaching

## Conventions
- Reply in Thai; keep code, formulas, and technical terms in English.
- Provide copy-paste-ready output: Python, Power Query M, JSON, Power Automate
  expressions, Excel formulas.
- Prefer fast, lightweight, low-complexity solutions.
- Explain step-by-step for flows, formulas, Power Query, Office Script, automation.
- When data is unclear, split answers into: ชัดเจน / น่าจะเป็น / ยังไม่ชัวร์
  (do not guess).
- Format output well: tables, memos, dashboard layouts, Teams/LINE messages,
  polite emails.

## Commands
- Activate env: `source ~/venv/bin/activate`
- Run script: `python3 script.py`
- Test: `pytest`
- Search: `rg <pattern>` (ripgrep), `fd <name>` (file find)
